# Трёхминутное демо контрольной точки B

[Смотреть запись экрана](rag-demo.webm). Запись показывает локальное приложение и вымышленные данные «Орбиты». Пояснения даны субтитрами. Вопросы отправляются в настоящий локальный API, источник открывается по ID фрагмента. Для демонстрации сетевого отказа один запрос специально прерывается в браузере.

| Примерное время | Сценарий |
|---|---|
| 0:00–0:24 | Библиотека с вымышленными документами |
| 0:24–0:48 | Вопрос о сертификате, принятии работы и 80% |
| 0:48–1:22 | Раскрытие цитаты и открытие выделенного фрагмента |
| 1:22–1:48 | Вопрос об отсутствующей аккредитующей организации и отказ |
| 1:48–2:28 | Смоделированный сетевой сбой, сохранённый ввод и ручной повтор |
| 2:28–3:01 | Корпус, конфигурация, результат 42/50 и слабый случай B27 из сохранённого отчёта |
| 3:01–3:20 | Ссылки на команды и ограничения |

Показанный слабый ответ взят из [сохранённого прогона](../data/eval/checkpoint-b-results.json), а не выбран из удачных ответов для записи. Итог оценки и ограничения доступны в [отчёте на 50 вопросах](rag-evaluation-50.md) и [списке ограничений](rag-limitations.md). Запись выполнена с отдельной SQLite-базой и loopback-серверами. Системные терминалы и ключи в кадр не попадают.

Для собственного прохода запустите приложение по [README](../README.md#запуск-интерфейса-и-api) и выберите индекс 600/50 по [инструкции переключения](chunking-experiment.md#воспроизведение-и-ручное-переключение). Повторные ответы и задержки могут отличаться от записи.
