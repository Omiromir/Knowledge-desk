# Своя база документов

Один экземпляр Knowledge Desk работает с одним активным корпусом. По умолчанию он использует демонстрационную «Орбиту». Для своего корпуса укажите `KNOWLEDGE_DESK_MANIFEST`. Задайте эти же настройки и при построении индекса, и при запуске FastAPI.

## 1. Подготовьте файлы

Сохраните документы в UTF‑8 как `.txt` или `.md`. PDF и сканы сначала преобразуйте в текст. В манифесте `path` указывает на локальный файл внутри папки манифеста, а `source` — на подпись или URL исходника. По адресу из `source` приложение ничего не загружает. `doc_id` и `source` должны быть уникальны в корпусе. Дата версии задаётся в формате `YYYY-MM-DD`.

Например, для `data/my-base/manifest.json` с файлом `data/my-base/notice.txt`:

```json
[
  {
    "doc_id": "notice-policy",
    "title": "Правила уведомления",
    "path": "notice.txt",
    "source": "Внутренний реестр · REG-004",
    "version_date": "2026-11-09"
  }
]
```

## 2. Постройте индекс и запустите API

Остановите текущий FastAPI, если он уже слушает порт 8000. Выполните в PowerShell из корня проекта:

```powershell
$env:KNOWLEDGE_DESK_MANIFEST = 'data/my-base/manifest.json'
$env:KNOWLEDGE_DESK_DB_PATH = 'data/my-base/catalog.sqlite3'
.\.venv\Scripts\python.exe -X utf8 ingest.py
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

При указании своего манифеста индекс по умолчанию создаётся рядом как `manifest.chroma`. `KNOWLEDGE_DESK_INDEX` задаёт другое место хранения. У каждого манифеста своя коллекция, даже при общем каталоге Chroma. `KNOWLEDGE_DESK_MAX_DISTANCE` меняет порог косинусного расстояния, по умолчанию `0.18`. Значение стоит проверить на вопросах с ответом и без ответа в новом корпусе. При обновлении текстов повторите индексацию. Для переключения манифеста перезапустите FastAPI с новыми переменными.

## 3. Откройте корпус в интерфейсе

Ответы и источники доступны сразу после индексации и запуска API. Чтобы видеть документы ещё и во вкладке «Документы», в отдельном терминале выполните:

```powershell
$env:KNOWLEDGE_DESK_MANIFEST = 'data/my-base/manifest.json'
.\.venv\Scripts\python.exe -X utf8 import_corpus.py
```

Ответ опирается на отрывки выбранного корпуса. Цитата показывает дату версии, а ссылка открывает документ с выделенным отрывком. Для своего корпуса резюме заявки использует общие типы `information_request`, `consultation` и `out_of_scope`.

Индекс хранится локально. Для генерации ответа сервер передаёт вопрос и отобранные отрывки OpenAI. Загружайте материалы, которые разрешено передавать этому провайдеру.
