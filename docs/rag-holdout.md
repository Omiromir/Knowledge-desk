# Проверка RAG на новых вопросах

Результат последующей доработки на этом и прежнем наборах описан в [отчёте об отказах и числах](rag-refusal-validation.md).

На отдельном наборе из 16 вопросов `document-grounded-v11` прошла **12/16**, предыдущая `document-grounded-v5` — **13/16**. Обе версии сохранили условия и источники на всех вопросах с ответом. Разница проявилась там, где нужных сведений не было.

| Проверка | V5 | V11 |
|---|---:|---:|
| Верные ответы с подтверждающими цитатами | 10/10 | 10/10 |
| Корректные отказы с пустыми цитатами | 3/6 | 2/6 |
| Полностью пройдено | 13/16 | 12/16 |
| Все ожидаемые документы среди top‑5 | 10/10 | 10/10 |

[Вопросы и эталоны](../data/eval/holdout.json) зафиксированы до запросов к модели. Проверка на точные совпадения с `dev.json` и набором поиска не нашла пересечений. Вопросы с ответом проверяют новые факты корпуса «Орбита», в том числе перенос заданий только при совпадении программ, приоритет срока из карточки и доступ к платформе после подтверждения зачисления. Вопросы без ответа намеренно близки к документам. Среди них есть запрос с известным расписанием и отсутствующей ссылкой, а также запрос о числовом пороге, которого в источнике нет.

В обоих прогонах использовались индекс 600/50, тот же корпус, снапшот `gpt-4.1-mini-2025-04-14`, top‑5 и порог расстояния `0,18`. В каждом вопросе модели передали одинаковые фрагменты в одинаковом порядке. При ручной проверке учитывались все существенные условия, опора утверждений на цитаты и корректный отказ, если отсутствует любая существенная часть запроса. [Полный прогон V5](../data/eval/holdout-v5.json) · [Полный прогон V11](../data/eval/holdout-v11.json)

## Где появились различия

| Вопрос | V5 | V11 |
|---|---|---|
| H12. Цена повторной карьерной консультации | Ответила, как согласовать встречу, и выставила `answerable=true`. Цена неизвестна. | Признала отсутствие цены, но добавила цитату к отказу. Сервер отклонил ответ с `invalid_citation`. |
| H13. Минимальная доля покрытия тестами | Корректно указала, что порог отсутствует. | Выдумала порог 70% и автоматический отчёт. В указанной цитате этих сведений нет. |
| H14. Расписание и точная ссылка на видеозвонок | Дала расписание и признала, что ссылки нет, с `answerable=true`. | Дала тот же частичный ответ. Правило оценки требует отказа при отсутствии одной из существенных частей. |
| H15. Продление срока при сбое платформы | Заявила, что автоматического продления нет. Корпус не описывает это правило. | Корректно указала, что срок продления неизвестен. |
| H16. Номер лицензии для сертификата | Корректно указала, что номер не найден. | Сделала вывод об отсутствии подтверждения лицензией. Цитата описывает учебный статус сертификата и не устанавливает этот факт. |

V11 перенесла работу с условиями на новые вопросы с ответом. Результат **20/20 на dev-наборе** оказался выше результата на новых вопросах, особенно по отказам. Сравнение с V5 выявило две новые ошибки и один исправленный случай. В H13 сработала специальная инструкция для доли обязательных требований. Модель указала число, которого нет в источнике, а проверка ID цитаты пропустила его, поскольку сам фрагмент был настоящим. Это наблюдения по одному прогону каждой версии на небольшом наборе из того же корпуса. Их достаточно, чтобы показать конкретные слабые места, но недостаточно для вывода о стабильности на других корпусах.

## Повторить прогон

Из корня проекта с настроенным серверным `OPENAI_API_KEY` запустите команды ниже. Они записывают новые отчёты. Сохранённые оценки привязаны к хэшам ответов, поэтому при изменении ответа нужна повторная сверка с эталоном и цитатами.

Текущая команда eval по умолчанию показывает расчёт без вызовов модели. Для платного повтора после проверки бюджета используйте [правила запуска eval](security-limitations.md#как-повторить-оценки).

```powershell
.\.venv\Scripts\python.exe -X utf8 -m backend.eval_rag --experiment --experiment-prompt document-grounded-v5 --cases data/eval/holdout.json --chunk-size 600 --index data/orbita-600-v1.chroma --output data/eval/replay-holdout-v5.json
.\.venv\Scripts\python.exe -X utf8 -m backend.eval_rag --experiment --experiment-prompt document-grounded-v11 --cases data/eval/holdout.json --chunk-size 600 --index data/orbita-600-v1.chroma --output data/eval/replay-holdout-v11.json
```
