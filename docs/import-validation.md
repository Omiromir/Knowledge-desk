# Проверка границы импорта

Проверки выполнены в отдельных временных каталогах с собственной Chroma. Рабочий индекс 600/50 не используется как цель импорта. [Фактический отчёт](../data/eval/boundary-checks-verified.json) содержит ожидаемые решения, имя файла, причину и число записей до и после для каждого случая.

| Случай | Ожидание | Фактический результат | До → после |
|---|---|---|---|
| `empty.txt` | Пропустить пустой текст | `skipped`, причина `empty text` | 1 → 1 |
| `whitespace.txt` | Пропустить текст из пробелов | `skipped`, причина `empty text` | 1 → 1 |
| `duplicate.txt` | Не добавлять копию существующего текста | `skipped`, причина указывает исходный `valid.txt` | 1 → 1 |
| `manifest.json` с оборванным JSON | Отклонить с причиной | `rejected`, имя манифеста и ошибка разбора | 1 → 1 |
| `missing-source.txt` без `source` | Отклонить метаданные | `rejected`, указаны файл и обязательные поля | 1 → 1 |
| Повтор корректного корпуса | Сохранить ID и количество | `complete`, 0 новых и 0 удалённых фрагментов | 1 → 1 |

`ingest.py` возвращает `status`, `files`, `before`, `after`, `upserted` и `removed`. Метаданные проверяются перед записью. Если один из документов отклонён, весь запуск получает `status=rejected`, код завершения 1 и сохраняет индекс до исправления входа. Пропущенные пустые и повторные файлы перечислены явно. При полностью пустом входе старый индекс сохраняется. Повтор корректного входа использует стабильные ID и не размножает фрагменты. Загрузка корпуса для поиска использует те же правила пропуска, что и импорт.

Автоматические тесты используют настоящую тестовую Chroma с фиксированными векторами, исключая загрузку E5 и платные вызовы. Проверочная команда дополнительно получает реальные E5-векторы во временной коллекции и выполняет один негативный `/ask` с моделью.

Итоговый полный запуск `pytest`: 126 тестов и 8 подтестов прошли. Проверки расчёта качества и стоимости входят в этот набор. В тесте перезапуска остановка сервера в Windows завершает также дочерний процесс Python, чтобы он не удерживал временный журнал.

```powershell
.\.venv\Scripts\python.exe -m pytest -q backend/tests/test_import_boundary.py backend/tests/test_corpus.py
.\.venv\Scripts\python.exe -X utf8 -m backend.check_rag_boundaries --output data/eval/boundary-replay.json
```
