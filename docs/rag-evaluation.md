# Ответы по базе и оценка RAG

Этот отчёт фиксирует сохранённый прогон демонстрационного корпуса с инструкцией `orbita-grounded-v1`. Текущий сервер использует `document-grounded-v16`. Её проверка описана в [отчёте об отказах и числах](rag-refusal-validation.md#повторная-проверка-h02), подключение другого корпуса — в [руководстве по корпусу](custom-corpus.md).

## Запуск

Откройте [«Ответы»](http://127.0.0.1:5173/#ask) или [Swagger](http://127.0.0.1:8000/docs). `POST /ask` принимает `{"question":"Можно ли сначала бесплатно попробовать занятие? Сколько оно длится?"}`. Максимум 1200 символов. Ответ содержит `answer`, `answerable` и `citations`. Каждая цитата включает `chunk_id`, `doc_id`, название документа и точный текст из индекса. В интерфейсе можно открыть целый документ с подсвеченным фрагментом. Исходник читается из манифеста корпуса независимо от импорта в SQLite FastAPI.

При недостатке сведений интерфейс показывает причину и предлагает подготовить заявку. В форме заявки пользователь решает, подставлять ли вопрос из поиска, и отдельно нажимает отправку. При сетевом сбое форма поиска сохраняет вопрос и предлагает повтор.

Поиск можно диагностировать отдельно от модели:

```powershell
.\.venv\Scripts\python.exe -X utf8 retrieve.py --question "Как долго доступна запись урока?"
```

## Настройки

- Модель эмбеддингов `intfloat/multilingual-e5-small` с ревизией `614241f622f53c4eeff9890bdc4f31cfecc418b3`. Индекс Chroma `knowledge-desk-orbita` использует косинусное расстояние. Точная версия корпуса и отпечаток состава индекса записаны в JSON-отчёте.
- Из пяти ближайших фрагментов модель получает только фрагменты с расстоянием `≤ 0,18`. На размеченном наборе порог сохраняет все ожидаемые источники для 15 положительных вопросов. Два далёких отрицательных вопроса имели минимальные расстояния около 0,22. Три отрицательных вопроса имели близкий контекст, поэтому одного порога недостаточно. Расстояние показывает близость векторов и не является вероятностью правильного ответа. [Метрика Chroma](https://docs.trychroma.com/docs/collections/configure)
- При пустом контексте модель не вызывается. Правило версии `cosine-0.18-explicit-year-v2` также отказывает, когда вопрос явно называет год, а среди прошедших порог фрагментов этот год отсутствует. Для оставшихся вопросов инструкция `orbita-grounded-v1` требует отказа при нехватке сведений и ссылок только на переданные фрагменты. Положительный ответ без цитат, повторяющийся, неизвестный или отфильтрованный `chunk_id` дают `502 invalid_citation`.
- Генерация использует алиас `gpt-4.1-mini` через OpenAI SDK `2.26.0`, строгую JSON-схему, максимум 512 выходных токенов, дедлайн провайдера 15 секунд и ноль автоматических повторов. Лимит `/ask` — 20 обращений к модели на процесс FastAPI. Он отдельный от `/ai/summary`.

## Оценка на 20 вопросах

[Размеченный набор](../data/eval/dev.json) включает 15 вопросов с ответом и 5 без ответа. [Результаты](../data/eval/results.json) содержат 100 найденных фрагментов, ID фактически переданного контекста, ответы, цитаты, коды ошибок, длительность и ручные оценки. [Ручные оценки](../data/eval/reviews.json) привязаны к хэшу конкретного ответа и его цитат. При изменении результата новый прогон оставляет оценку пустой до повторной проверки.

В первом прогоне R17 получил `502 invalid_citation`. Ошибка и длительность сохранены в `initial_attempt`. После добавления правила про год повторно проверен только R17 с локальным поиском и без вызова модели. Остальные вопросы это правило не затрагивает. Таким образом, снимок содержит один реальный прогон и одну целевую локальную перепроверку, а не повторную генерацию 20 ответов.

| Проверка | Результат |
|---|---:|
| Вопросы с ответом, `answerable=true` | 15/15 |
| Вопросы без ответа, `answerable=false` и пустые цитаты после перепроверки | 5/5 |
| Положительные ответы, прошедшие полную ручную сверку | 10/15 |
| Положительные ответы с неподтверждённой деталью | 4/15 |
| Положительные ответы с неполным существенным условием | 1/15 |

### Пять сверенных вопросов из набора поиска

| Вопрос | Что подтверждает источник |
|---|---|
| R01. Навыки для курса тестирования | Функции, списки и словари, входное задание со строками и pytest перечислены в `python-testing-000-8a24c1de5e3976821f7a`. |
| R03. Вводное занятие | Бесплатность, 30 минут, заявка с курсом и удобным интервалом, подтверждение и пробное упражнение есть в `intro-enrollment-000-04c0f38e0f1dd6af0f36`. |
| R05. Два платежа | Равные части без доплаты, первый после подтверждения места, второй до четвёртой недели и бесплатное вводное занятие есть в `payment-terms-000-a6599e056c60bb15a866`. |
| R06. Портфолио | Допуск после одного курса, 40 минут, обсуждение портфолио, обезличенные проекты и подбор примеров подтверждены `consult-career-000-6d0064c31fe128e650f9`. |
| R07. Поздний перенос | 12 часов, данные для заявки, подтверждение, снятие встречи и возможность запросить другую есть в `consult-reschedule-000-51c5851a1da890f5ed5d`. |

### Ошибки, которые остались в снимке

- **R02** переносит правило из расписания аналитики на курс Python. **R04** упускает условие свободного места. **R08** упускает условие «прошло больше суток» перед обращением в поддержку и расширяет исключение о групповых обсуждениях на занятия.
- **R10** неверно привязывает дополнительный срок выдачи сертификата. **R13** превращает оборванную фразу о содержимом учебных файлов в общий запрет их прилагать.
- Пропуска ожидаемых документов в отобранном контексте на этой выборке не было. Проверка `chunk_id` защищает от ссылок на отсутствующие фрагменты. Достоверность отдельного утверждения проверяется сверкой текста с источником.

Для нового оценочного прогона из корня проекта с настроенным `OPENAI_API_KEY` выполните одну команду. Она пишет новый отчёт и сохраняет исходный снимок:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m backend.eval_rag --output data/eval/replay.json
```

На машине с ограниченной памятью запускайте оценку отдельно от FastAPI, если сервер уже загрузил E5. Скрипт оценки использует локальный индекс и вызывает модель напрямую через тот же адаптер.
