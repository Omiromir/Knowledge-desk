# Контрольная точка B — оценка на 50 вопросах

Сохранённый прогон от 20 ноября 2026 года дал **42/50 полностью пройденных случаев**. Все ожидаемые документы найдены среди top‑5 для 38 вопросов с ответом. Итоговые ответы содержат пропуски условий, неподтверждённые утверждения и ложные отказы.

Разметка [checkpoint-b.json](../data/eval/checkpoint-b.json) содержит 50 уникальных ID и вопросов, эталон смысла, ожидаемые `doc_id`, признак ответа, тип вопроса и группу. R01–R20 помечены `tuning_dev`. B01–B30 помечены `control_new` и написаны перед первым прогоном. Они отличаются от прежних dev-вопросов и 16 вопросов holdout. Среди новых вопросов есть перефразировки, уточнения, сравнения нескольких источников и 7 вопросов без ответа. Вместе с пятью прежними отказами получается 12 случаев без ответа. Разметка и схема API после просмотра результатов не менялись. При дальнейшем использовании B-вопросов для доработки инструкции они переходят в примеры для настройки.

[Полные результаты](../data/eval/checkpoint-b-results.json) включают все 50 случаев, top‑5 с текстами, переданные ID, сырые ответы черновика и проверяющей модели, серверный результат, ошибку и длительность. [Ручные оценки](../data/eval/checkpoint-b-results.reviews.json) привязаны к хэшу результата. [Сводка](../data/eval/checkpoint-b-summary.json) пересчитывает показатели из этих записей. Полный балл требует всех запрошенных фактов и существенных условий и подтверждения утверждений цитатами. Частичный ответ и тайм-аут считаются неуспехом. p95 вычислен методом ближайшего ранга на всех 50 длительностях, включая отказ и тайм-аут. Hit@5 считается только по 38 вопросам с ожидаемыми источниками.

## Зафиксированные компоненты

- Вымышленный корпус «Орбита», 20 документов. SHA‑256 корпуса `21ff56bbc16cb33b47c1aa229ee4d002090694f8e973cf4fd427e944d1ad2904`.
- Chroma 600/50, 25 фрагментов, косинусное расстояние, top‑5 и порог `0,18`. E5-small с ревизией `614241f622f53c4eeff9890bdc4f31cfecc418b3`. Отпечаток ID индекса и версии библиотек записаны в JSON.
- Инструкция `document-grounded-v16`, включая специальную инструкцию для доли требований и отдельную проверку черновика. Все тексты и их SHA‑256 сохранены в отчёте. Модель `gpt-4.1-mini-2025-04-14`, SDK 2.26.0, до 512 выходных токенов на вызов и до 15 секунд на весь сценарий генерации и проверки, ноль автоматических повторов.
- SHA‑256 набора `5e3e804306d0c3cb688449944fc354fec9d93787c914f241e89ffbb1630a9af5`. Текущий набор из 50 случаев отдельно хранит принадлежность к настройке и контролю.

## Токены и стоимость

Для 85 полученных ответов провайдера сохранён фактический `usage` обоих этапов. Всего **142 729 входных, 0 кэшированных и 10 014 выходных токенов**. Один вызов R02 завершился тайм-аутом, его полный usage неизвестен. Полная стоимость прогона и сумма в биллинге отмечены как неизвестные.

По стандартному тарифу, проверенному **20 ноября 2026 года**, миллион входных токенов стоит $0,40, кэшированных $0,10, выходных $1,60. Расчёт по известному usage равен `(142729 × 0.40 + 10014 × 1.60) / 1000000 = $0.073114`. Для 30 контрольных вопросов известны все возвращённые показатели, расчётная стоимость составляет $0.045970. [Тариф GPT‑4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini#pricing)

## Пять слабых примеров

| Случай | Наблюдение | Причина и направление исправления |
|---|---|---|
| R04 | Ответ назвал два учебных дня и форму заявки, но пропустил свободное место | Источник и условие были в контексте. Пропуск условия при генерации, пропущенный проверяющей моделью |
| B17 | Сравнение итоговых проектов завершилось отказом | Обе цитаты найдены. В дословную выдержку модель внесла управляющий символ вместо тире. Сервер отклонил повреждённое подтверждение |
| B20 | Сравнение встреч на 25 и 20 минут завершилось отказом | Модель добавила вычисленную разницу «5 минут». Числовая проверка заблокировала число, которого нет цифрами в источниках. Для улучшения нужен отдельно проверяемый режим вычислений или ответ только исходными длительностями |
| B23 | Отказ на вопрос об обещании зачёта при разных программах | Источник найден. Черновик превратил достаточное условие совпадения программ в категоричный запрет при различии. Проверяющая модель это заблокировала. Требуется формулировка границы обещания без нового запрета |
| B27 | На вопрос о расписании и пароле выдано расписание с утверждением, что пароль не нужен | Пароля нет в документах. Модель спутала запрет присылать пароль в поддержку с отсутствием пароля для входа. Проверяющая модель пропустила неполный и неподтверждённый ответ |

Также R02 завершился тайм-аутом, B01 добавил исполнителя подтверждения, B18 превратил более позднее изучение React в запрет. Эти случаи и оценки сохранены вместе с успешными. После разбора инструкция и генерация не дорабатывались. Обнаруженные дефекты показаны в [демо](rag-demo.webm) и перечислены в [ограничениях](rag-limitations.md).

## Воспроизведение

Из корня проекта установите зависимости поиска и подготовьте индекс. Первая загрузка E5 требует интернета; повторная индексация неизменного корпуса сохраняет ID.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-rag.txt
.\.venv\Scripts\python.exe ingest.py --chunk-size 600 --index data/orbita-600-v1.chroma
```

С серверным `OPENAI_API_KEY` выполните один платный прогон. Выбирайте новое имя файла, чтобы сохранить текущую точку отсчёта.

```powershell
.\.venv\Scripts\python.exe -X utf8 -m backend.eval_rag --experiment --experiment-prompt document-grounded-v16 --cases data/eval/checkpoint-b.json --chunk-size 600 --index data/orbita-600-v1.chroma --output data/eval/checkpoint-b-replay.json
```

После ручной сверки результата сохраните оценки в `checkpoint-b-replay.reviews.json` с ключами ID, `result_sha256`, `grade`, `errors` и `note`. Для пересчёта сохранённого оценённого отчёта достаточно одной команды.

```powershell
.\.venv\Scripts\python.exe -m backend.report_rag_eval data/eval/checkpoint-b-results.json --output data/eval/checkpoint-b-summary-replay.json
```

Повторные ответы модели и задержки могут отличаться. Воспроизводятся входы, настройки, процедура и расчёт по сохранённым данным.
