# Ошибки поиска и генерации

В двух [прогонах разбиения](chunking-experiment.md) найдено 10 неудачных ответов с учётом частичных. Для каждой строки вопрос, top‑5, переданный контекст и ответ доступны по ID в отчёте [300](../data/eval/chunking-300.json) или [600](../data/eval/chunking-600.json).

| Прогон, вопрос | Причина | Что показала сверка |
|---|---|---|
| 300, R02. Вечерний Python | `generation_error` | Расписание и правило о публикации записи найдены. Ответ сформулировал 24 часа двусмысленно как срок доступности. |
| 300, R03. Пробное занятие | `generation_error` | Цитата говорит о подтверждении через платформу. Ответ приписал платформе также подачу заявки. |
| 300, R06. Портфолио | `generation_error` | Карьерная консультация найдена. Модель добавила ограничение для консультации с преподавателем и порядок из другого вида консультации. |
| 300, R07. Перенос консультации | `retrieval_error` | Документ найден. Переданные отрывки описывают последствие опоздания, а порог 12 часов остался за пределами контекста. Ответ добавил публикацию в календаре без опоры на цитату. |
| 300, R10. Порог для сертификата | `generation_error` | Контекст подтверждает 80% и принятую итоговую работу. Ответ потребовал закрыть все задания. |
| 300, R12. Расписание и цена | `retrieval_error`, `invalid_citation` | Оба документа в top‑5. Переданный отрывок об оплате не содержит 150 единиц за аналитику. Ответ отклонён проверкой цитат. |
| 300, R13. Консультация с преподавателем | `retrieval_error` | В первом фрагменте есть 20 минут. Абзац о подготовке отсутствует в контексте, и модель дала неполный ответ. |
| 300, R15. Запись и сертификат | `generation_error` | Оба срока и точный порог доступны в контексте. Дополнение про 80% допускает неверное прочтение. |
| 600, R07. Перенос консультации | `generation_error` | Третий фрагмент содержит порог и последствие. Модель добавила, что позднюю заявку не примут. |
| 600, R15. Запись и сертификат | `generation_error` | Источники подтверждают оба срока. Модель снова превратила условную оговорку про незакрытые задания в общее требование. |

Итого **7 `generation_error` и 3 `retrieval_error`** по основной причине. Все три ошибки поиска связаны с полнотой фрагмента. Дополнительные признаки включают одно отклонение цитат сервером и неподтверждённые или двусмысленные утверждения. Ошибочных отказов, ответов на вопросы вне корпуса и сетевых ошибок провайдера в обоих прогонах было 0.

## Пять повторов с выбранным контекстом

[Выбор фрагментов](../data/eval/manual-context.json) и [результаты повторов](../data/eval/manual-context-results.json) содержат ID, диапазоны текста и сверенные ответы. Выбраны обе оставшиеся ошибки индекса 600 и три неудачи индекса 300. В этих повторах фрагменты выбраны вручную из индекса 600. Настройки генерации сохранены.

| Случай | Что изменилось в ответе |
|---|---|
| R07 | Один фрагмент про перенос дал порог 12 часов и последствия без утверждения об отказе принять заявку. |
| R10 | Фрагмент о сертификате подтвердил 80%, принятие работы и необязательность эфиров. Общее требование закрыть все задания пропало. |
| R12 | Два фрагмента подтвердили субботнее расписание и цену. Обе цитаты прошли серверную и ручную проверку. |
| R13 | Фрагмент о преподавателе подтвердил длительность, описание проблемы и пример того, что уже пробовали. |
| R15 | Два фрагмента подтвердили оба срока и порог 80% без дополнительного требования закрыть все задания. |

Все пять повторов прошли ручную сверку. Один повтор на вопрос показывает, что правильный контекст позволил получить подтверждённый ответ. Генерация может варьироваться между вызовами. Повторы использовали 2 771 входной и 520 выходных токенов. Расчётная стоимость $0.0019404. [Тариф GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini#pricing)

Текущая команда eval по умолчанию показывает расчёт без вызовов модели. Для платного повтора после проверки бюджета используйте [правила запуска eval](security-limitations.md#как-повторить-оценки).

```powershell
.\.venv\Scripts\python.exe -X utf8 -m backend.eval_rag --cases data/eval/dev.json --experiment --chunk-size 600 --index data/orbita-600-v1.chroma --manual-context data/eval/manual-context.json --output data/eval/replay-manual.json
```

По результатам эксперимента проверена инструкция, которая ограничивает ответ запрошенными фактами и требует сохранять область действия условий. [Сравнение на полном dev-наборе](rag-prompt-comparison.md) включает R07 и R15.
