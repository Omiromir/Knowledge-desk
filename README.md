# Knowledge Desk

Небольшой Python-проект — заготовка для персонального AI-помощника. Сейчас приложение выводит приветственное сообщение; это начальная точка для будущих функций Knowledge Desk.

## Требования

- Python 3

## Запуск

Из корневой папки проекта:

```powershell
py main.py
```

Ожидаемый вывод:

```text
Knowledge Desk - Your AI Assistant
```

## Виртуальное окружение (необязательно)

Создать окружение:

```powershell
py -m venv .venv
```

Активировать в PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

В `cmd.exe` используйте:

```cmd
.venv\Scripts\activate.bat
```

После активации запускайте приложение командой `python main.py`. Чтобы выйти из окружения, выполните `deactivate`.
