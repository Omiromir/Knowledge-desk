# Python с нуля

Курс «Python с нуля» рассчитан на взрослых без опыта программирования. Перед началом достаточно уметь пользоваться файлами и браузером. Программа длится восемь недель: переменные, условия, циклы, функции, файлы и базовая отладка. Итоговый проект представляет собой консольный каталог домашних расходов.

Для работы нужен компьютер с Python 3.12 и редактором кода. На первой встрече группа проверяет установку, запускает первую программу и знакомится с учебной платформой. Если установка не проходит, участник может выполнить первую практику в браузере.

Оценка итогового проекта учитывает корректность ввода, понятность функций и работу с файлом. Автоматические тесты в этой программе отдельно не изучаются: для этого есть следующий курс по тестированию.
