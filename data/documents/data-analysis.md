# Аналитика данных

Курс «Аналитика данных» длится девять недель. Первые три недели посвящены очистке таблиц и сводным отчётам, следующие три — SQL, группировке и соединению таблиц. Последний блок посвящён графикам и объяснению выводов.

Знание Python для начала не требуется. Участники работают с подготовленными вымышленными наборами продаж и посещаемости. На первой практике проверяют пропуски и дубликаты, затем строят воспроизводимый отчёт.

Итоговый результат состоит из таблицы проверенных данных, запросов SQL и короткой записки с двумя графиками. Оценка учитывает проверяемость расчётов и корректное объяснение ограничений набора.
