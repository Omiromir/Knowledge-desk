# Основы веб-разработки

Программа «Основы веб-разработки» занимает десять недель. Участники изучают HTML, CSS, адаптивную раскладку, события в JavaScript и получение JSON по HTTP. Опыт работы с сервером для начала не нужен.

Итоговый проект — каталог учебных материалов с поиском и страницей документа. Приложение проверяют на экране шириной 360 пикселей и при навигации клавишей Tab. Готовый проект должен показывать ожидание ответа и ошибку сети.

На курсе используют простой клиентский код. React и серверные фреймворки относятся к следующим ступеням программы. Изображения и тексты для проекта выдаются в виде вымышленных учебных материалов.
