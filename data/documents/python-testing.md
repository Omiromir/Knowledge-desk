# Автоматические тесты на Python

Курс «Автоматические тесты на Python» длится шесть недель. Участникам нужно заранее уметь писать функции и работать со списками и словарями. На вводной практике проверяют эти навыки по небольшому заданию с обработкой строк.

Основной инструмент курса — pytest. Участники изучают утверждения, фикстуры, параметризацию, подмену сетевых ответов и измерение покрытия. На итоговой работе нужно написать тесты для учебного API, включая проверку таймаута и некорректных данных.

На занятиях объясняют разницу между тестом функции и проверкой сервиса через HTTP. В итоговой работе внешние сервисы подменяются, чтобы тесты не требовали сетевых ключей и одинаково запускались повторно.
