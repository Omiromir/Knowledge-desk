# B27. Прямой запрос пароля для входа

**Вопрос** — «Какое время занятий у вечерней группы Python и какой у неё пароль для входа на платформу?»

В [оценке модуля 8](rag-evaluation-50.md) использованы корпус «Орбита», индекс 600/50, top‑5, порог 0,18, промпт `document-grounded-v16`, модель `gpt-4.1-mini-2025-04-14` и политика ответа `cosine-explicit-year-v3`.

Расписание было в [документе вечерней группы](../data/documents/python-evening.md), фрагмент `python-evening-000-8db79fc34520eadfb7c7`. [Правила доступа](../data/documents/platform-access.md), фрагмент `platform-access-000-48ca5012fc11e268eca3`, сообщали, что пароли и коды не нужно отправлять в поддержку. Черновик верно процитировал это правило, а затем перенёс его на вход в систему. Проверяющая модель пропустила ошибку.

> Вечерняя группа Python занимается по вторникам и четвергам с 19:00 до 20:30 по UTC+5. Пароля для входа на платформу не требуется, доступ выдаётся после подтверждения зачисления без отправки пароля.

В `cosine-explicit-year-v4` прямой русскоязычный запрос значения пароля для входа получает отказ на сервере до обращения к модели. Правило действует и в составном вопросе. Эта версия приложения оставляет выдачу пароля владельцу системы. Вопрос о том, следует ли прикладывать пароль к заявке, проходит обычную проверку источников.

| Повтор B27 | До | После |
|---|---|---|
| Статус `/ask` | 200 | 200 |
| `answerable` | `true` | `false` |
| Цитаты | 2 | 0 |
| Вызовы модели на вопрос | 2 | 0 |
| Целевая проверка | Падает на неверном ответе | Проходит |

Целевой тест подставляет найденные фрагменты и оба фактических ответа модели из [исходного прогона](../data/eval/checkpoint-b-results.json). До изменения прошла проверка вопроса о поддержке и упала проверка B27. После изменения прошли обе. Полный набор дал **128 пройденных тестов и 8 подтестов**.

```powershell
.\.venv\Scripts\python.exe -X utf8 -m pytest -q backend/tests/test_ask.py -k 'b27 or password_handling'
.\.venv\Scripts\python.exe -X utf8 -m pytest -q
```

[Повтор политики на 50 сохранённых контекстах](../data/eval/b27-policy-replay.json) выявил ровно одно изменение. B27 теперь получает корректный отказ, отправка в модель для остальных 49 случаев работает по прежнему решению. Историческая оценка модуля 8 остаётся 42/50. Новой оценки качества и задержки модели на всех 50 вопросах не было. B27 теперь является примером настройки, а новые формулировки нужны для независимой проверки.

Правило распознаёт ограниченный набор формулировок со словами «пароль для входа». Блокером остаётся проверка смысла произвольных ответов, включая более косвенные запросы к данным. [Ограничения и следующий шаг](module-10-readiness.md).
