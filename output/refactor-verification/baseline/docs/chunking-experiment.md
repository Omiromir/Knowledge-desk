Проверка качества учитывает эталон, существенные условия и все факты в ответе, включая дополнительные утверждения. Корректный отказ даёт полный балл. Локальная задержка поиска включает эмбеддинг запроса и обращение к Chroma. p95 считается по 20 измерениям методом ближайшего ранга. Полная задержка включает провайдера и отражает один прогон каждого варианта. Стоимость рассчитана по `usage` и стандартному тарифу на дату прогона. ### Что зафиксировано

[Прогон 300](../data/eval/chunking-300.json) и [прогон 600](../data/eval/chunking-600.json) содержат по 20 случаев, полную выдачу, фактически переданные ID, оценки, хэши и настройки. Корпус, dev-набор, E5 и его ревизия, инструкция `orbita-grounded-v1`, снапшот `gpt-4.1-mini-2025-04-14`, top‑5, порог `0,18` и правила отказа одинаковы. На прогоне 300 у R12 сохранён код `invalid_citation`, возвращённого приложением ответа нет. Сырой текст этого ответа не был записан первым прогоном.

[Исходный отчёт модуля 6](../data/eval/results.json) сохранён побайтно. Его SHA‑256 `a3051b982fb927f34e1e5dad56fe93062188df5137c59e05955413d8097d8564`. Исторические 15/20 включают локальную перепроверку R17. Новый эксперимент фиксирует снапшот модели, а правила отказа используют текущую реализацию с тем же наблюдаемым решением по R17, R19 и R20. Историческую оценку используем как справочную. Проверка обоих новых индексов подтвердила уникальность ID и точное совпадение всех 85 фрагментов с исходниками. Повторная индексация изменила 0 записей.

### Воспроизведение и ручное переключение

Из корня проекта запустите PowerShell с серверным `OPENAI_API_KEY`. Для нового замера используйте новые каталоги и имена отчётов. `--build` выполняет проверку лимита E5 до записи и замеряет построение. `--output` открывает новый файл и защищает существующий отчёт. Для повторной ручной оценки сверяйте ответ и каждую цитату с эталоном.

Текущая команда eval по умолчанию показывает расчёт без вызовов модели. Для платного повтора после проверки бюджета используйте [правила запуска eval](security-limitations.md#как-повторить-оценки).

```powershell
$env:HF_HUB_OFFLINE = '1'  # после первой загрузки E5
$env:TRANSFORMERS_OFFLINE = '1'
$env:OMP_NUM_THREADS = '2'
$env:MKL_NUM_THREADS = '2'
.\.venv\Scripts\python.exe -X utf8 -m backend.eval_rag --cases data/eval/dev.json --experiment --build --chunk-size 300 --index data/replay-300.chroma --output data/eval/replay-300.json
.\.venv\Scripts\python.exe -X utf8 -m backend.eval_rag --cases data/eval/dev.json --experiment --build --chunk-size 600 --index data/replay-600.chroma --output data/eval/replay-600.json
```

Для ручной проверки в приложении запустите FastAPI с выбранным индексом в отдельном PowerShell. При необходимости сначала восстановите индекс командой `ingest.py` с `--chunk-size 600 --index data/orbita-600-v1.chroma`. Оценка в этой таблице получена с `orbita-grounded-v1`. Рабочая инструкция описана в [сравнении инструкций](rag-prompt-comparison.md).

```powershell
$env:KNOWLEDGE_DESK_INDEX = 'data/orbita-600-v1.chroma'
$env:KNOWLEDGE_DESK_CHUNK_SIZE = '600'
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

Чтобы вернуться к стандартному индексу `data/chroma` с размером 400/50, остановите этот процесс, выполните `Remove-Item Env:KNOWLEDGE_DESK_INDEX, Env:KNOWLEDGE_DESK_CHUNK_SIZE` и запустите FastAPI снова. Откройте [«Ответы»](http://127.0.0.1:5173/#ask).
