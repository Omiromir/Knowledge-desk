# Консультация по выбору курса

Индивидуальная консультация по выбору программы длится 25 минут и проходит онлайн. Методист уточняет опыт, цель обучения и время, которое человек готов уделять практике. По итогам он предлагает одну или две программы для сравнения.

Для записи достаточно указать, чем участник занимался раньше и какую задачу хочет решить. Если важен сменный график, его можно указать без личных расписаний и контактных данных. Время встречи согласовывают после получения заявки.

Консультация подходит тем, кто сравнивает направления или выбирает между вводным и продвинутым курсом. Общий вопрос о содержании одной программы можно задать без индивидуальной встречи.
