# Расписание потока тестирования

У группы «Автоматические тесты на Python» занятия проходят по понедельникам и средам с 18:30 до 20:00 по UTC+5. Понедельник отведён для разбора темы, среда — для совместной работы с примерами и проверки решений.

В последнюю среду курса вместо обычной практики проходит демонстрация итоговых проектов. Материалы для демонстрации загружают до 18:00 предыдущего дня. Изменения времени публикуют в календаре потока.

Отдельное окно для консультаций преподавателя не входит в расписание группы. Его согласовывают через форму заявки, если возник вопрос по итоговой работе.
