# Дизайн Knowledge Desk

## Референс

Рабочая область следует тёмному интерфейсу Linear после обновления в марте 2026 года. Слева приглушённая навигация, справа рабочая поверхность с небольшим скруглением и отдельными строками для текущего раздела и управления списком. На мобильной ширине основные разделы доступны в нижней навигации. [Linear UI refresh](https://linear.app/now/behind-the-latest-design-refresh) · [Linear Mobile](https://linear.app/changelog/2025-10-16-mobile-app-redesign)

## Компоновка

- Боковая панель шириной 216px на широком экране. Заголовок раздела занимает 45px. Заголовок группы и счётчик используют фактическое число результатов. Источник расположен в правой колонке. На телефоне источник переносится под название и фрагмент.
- Поиск проверяет заголовок и весь текст. Иконка в боковой панели и Ctrl+K / Cmd+K открывают список и переводят фокус в поле поиска. Возврат из документа восстанавливает запрос, позицию и фокус.
- Ридер использует компактную закреплённую панель и область свойств справа. На телефоне свойства идут под заголовком. Кегль запоминается в браузере, прогресс появляется у длинных документов.
- В разделе заявок история слева, форма справа. Контекстная форма показывает название документа. Строка истории открывает экран заявки с вопросом, лентой активности и свойствами. Поле ответа внизу ленты следует компоновке обсуждений Linear. UUID доступен в деталях. [Экран обсуждения Linear](https://linear.app/docs/comment-on-issues)

## Цвета и состояния

| Назначение | Значение |
|---|---|
| Холст и сайдбар | #101011 |
| Рабочая поверхность | #161617 |
| Группа записей | #1c1c1e |
| Наведение | #202022 |
| Выбранный раздел | #262628 |
| Основной и вторичный текст | #f0f0f1 и #a2a2a7 |
| Фокус и ссылки | #9c9ff8 |
| Основное действие | #4f53b7 |
| Скругление навигации и контролов | 8px |
| Скругление рабочей области | 11px |

Наведение меняет тон поверхности. Клавиатурный фокус использует отдельный контрастный контур. Индикатор загрузки учитывает настройку reduced motion. Загрузка, пустой результат и сетевая ошибка имеют отдельные состояния. Ошибки формы сохраняют ввод, подтверждение появляется после получения id от API.

## Граница публикации

Приложение остаётся локальным. До публичного доступа нужны вход и серверные проверки ролей и владельцев. Оставшиеся ограничения описаны в [архитектуре проекта](docs/architecture.md).
